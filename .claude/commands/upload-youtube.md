# /upload

Upload the generated video to YouTube.

## Steps

### Step 1: Generate metadata

Generate metadata using the same steps as the `/gen-metadata` command and save to `.cache/pipeline/05_metadata.json`.
(To regenerate metadata only, run `/gen-metadata` standalone.)

### Step 2: YouTube upload (Python)

Run the following with the Bash tool (`--publish-at` is optional):

```bash
cd /c/Users/furag/Documents/prog/python/news_video_maker_en && uv run python -m news_video_maker.uploader.youtube [--publish-at YYYY-MM-DDTHH:MM:SSZ]
```

When `--publish-at` is specified, the video is uploaded as `private` and automatically made public at the given time (UTC).

After execution, record the YouTube URL (e.g., `https://youtu.be/VIDEO_ID`).

### Step 3: Post pinned comment

After a successful upload, immediately post the pinned comment.

1. Read `.cache/youtube_comments.md` with the Read tool. If the URL for the relevant video entry is `(not yet uploaded)`, replace it with the actual YouTube URL using the Edit tool.

2. Run the following to post the comment (`VIDEO_ID` is obtained from the upload result):

```bash
cd /c/Users/furag/Documents/prog/python/news_video_maker_en && uv run python scripts/post_comments.py --video-id VIDEO_ID
```

> **How it works**: Private or scheduled videos are temporarily set to unlisted → comment posted → automatically restored to the original state (private or scheduled).

Report the result (comment ID or error).

## Prerequisites

- `YOUTUBE_CLIENT_SECRET_PATH` must be set in `.env`
- `.cache/pipeline/04_video_path.txt` must exist
- `.cache/pipeline/02_selected.json` and `.cache/pipeline/03_script.json` must exist
- `.cache/pipeline/05_metadata.json` is auto-generated by this command (if absent, `youtube.py` falls back to defaults)

## Channel branding settings (.env)

Customize the video description, tags, and privacy via these environment variables:

| Variable | Default | Description |
|---|---|---|
| `CHANNEL_NAME` | `AI News in 60 Seconds` | Channel name shown in the video hook badge |
| `CHANNEL_HASHTAGS` | `#AINews #TechNews #AI #ShortNews #Shorts` | Hashtags used in description and tags |
| `CHANNEL_DESCRIPTION_FOOTER` | `Daily AI and tech news in 60 seconds.\nSubscribe for the latest updates!` | Footer text in the description |
| `YOUTUBE_PRIVACY` | `public` | Privacy setting (`public` / `unlisted` / `private`) |

## First-time authentication

On the first run, a Google OAuth screen will open in your browser.
After authentication, credentials are cached in `token.json` and reused automatically on subsequent runs.

## Error handling

- If `client_secret.json` is not found: guide the user through the setup steps and stop
- Quota exceeded: prompt to retry the next day and stop (video file is preserved)
- Authentication failure: delete `token.json` and prompt for re-authentication
